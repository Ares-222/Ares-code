# ◆ ARES CODE — пошаговая настройка с нуля до рабочего терминала

Инструкция написана «для нажатий»: каждое действие — отдельный шаг.
Ты стартуешь с готовым `.env` (в него уже вписаны бот, твой ID и 4 ящика) —
останется вставить только GLM-ключ и адрес туннеля.

---

## ЧАСТЬ 1. Установка программ (один раз)

### Шаг 1. Python 3.11+
1. Открой https://www.python.org/downloads/ → жёлтая кнопка **Download Python 3.12** → установи.
2. ⚠️ На первом экране установщика **обязательно поставь галочку «Add python.exe to PATH»**, потом Install Now.
3. Проверка: Win+R → набери `cmd` → Enter → в чёрном окне набери `python --version` → должно быть `Python 3.12.x`.

### Шаг 2. Node.js (нужен только для OmniRoute)
1. Открой https://nodejs.org → **LTS** → установи (галочки по умолчанию).
2. Проверка в том же cmd: `node -v` → `v22.x.x`.

### Шаг 3. Распакуй проект
Распакуй `ares_code.zip` в любое место, например `C:\ares\` — получится папка
`C:\ares\ares_code\` со всеми файлами (api.py, core\, webapp\, …).

## ЧАСТЬ 2. Секреты: файл .env

### Шаг 4. Переименуй env.local.txt в .env
В скачанном наборе есть файл **`env.local.txt`** — это твой готовый `.env`,
в него уже вписаны: токен бота, твой ID `5188446459`, 4 почтовых ящика.
1. В проводнике: Вид → ✅ «Расширения имён файлов» (иначе Windows спрячет .txt).
2. Переименуй `env.local.txt` → `.env` (точка в начале, без хвоста).
3. Положи его в корень `C:\ares\ares_code\` рядом с api.py.
4. Открой его Блокнотом и **вставь свой GLM-ключ** в строку
   `GLM_API_KEY=ВСТАВЬ_СЮДА_GLM_КЛЮЧ` (ключ лежит в кабинете z.ai → API Keys).
   Сохрани (Ctrl+S) и закрой.

> Позже в этот же файл ты двумя строками допишешь `BASE_URL=...` и
> `OMNIROUTE_API_KEY=...` — см. Части 4 и 6.

## ЧАСТЬ 3. Запуск (каждый раз — 2 команды)

### Шаг 5. Установка библиотек (один раз)
1. Открой папку `C:\ares\ares_code` в проводнике.
2. Кликни в адресную строку проводника, сотри путь, набери `cmd` → Enter —
   откроется чёрный терминал уже в нужной папке (или Shift+правый клик по
   пустому месту → «Открыть окно PowerShell здесь»).
3. По очереди:
```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python check_install.py
```
   Все строки должны быть `[OK]`. Затем проверка с сетью:
```
python check_install.py --net
```
   Она покажет имя бота (`@...`), пинг GLM и 4 ящика почты. WARN по пустым
   GEMINI/OPENROUTER/OMNIROUTE — это нормально (резервы настраиваются позже).

### Шаг 6. Запуск ARES
В том же окне (venv должен быть активен — в начале строки видно `(.venv)`):
```
python api.py
```
Появятся строки `ARES CODE запущен…` и `бот запущен (polling)`. **Это окно не
закрывай** — в нём живёт весь ARES: API, Telegram-бот и фоновый уборщик.
Проверка: в браузере открой http://localhost:8000/healthz → `{"ok": true…}`.

## ЧАСТЬ 4. HTTPS-туннель (чтобы кнопка Mini App работала)

Telegram открывает Mini App только по **HTTPS**. На своём компе HTTPS даёт
бесплатный туннель Cloudflare.

### Шаг 7. Скачай cloudflared
1. Открой https://github.com/cloudflare/cloudflared/releases/latest
2. Скачай **cloudflared-windows-amd64.exe** (для Мак — cloudflared-darwin.tgz, Linux — .deb).
3. Переименуй в `cloudflared.exe` и положи в `C:\ares\`.

### Шаг 8. Подними туннель
1. Открой **второе** окно cmd: Win+R → `cmd` → Enter, затем:
```
cd C:\ares
cloudflared.exe tunnel --url http://localhost:8000
```
2. В выводе найди строку вида
   `https://random-words-1234.trycloudflare.com` — **скопируй её**.
3. Останови ARES в первом окне: Ctrl+C.
4. В .env допиши (Блокнот):
```
BASE_URL=https://random-words-1234.trycloudflare.com
```
5. Снова запусти `python api.py` (не забудь `.venv\Scripts\activate` в новом окне).

> ⚠️ Бесплатный quick-туннель меняет адрес при каждом перезапуске cloudflared —
> тогда просто повтори шаги 8.2–8.4 (адрес в BASE_URL + перезапуск ARES).
> Постоянный адрес без денег: **Render.com** — см. Часть 8.

### Шаг 9. Открой терминал в Telegram
1. Telegram → твой бот → **/start** → придёт кнопка **◆ Open Ares Code** → нажми.
2. Откроется тёмный терминал с красным ромбом. Ты владелец (ID вписан) — доступ
   сразу, гейт-экран увидят только чужие люди.
3. В боте также появится кнопка меню «◆ Open Ares Code» рядом с полем ввода
   (ставится автоматически при старте, когда BASE_URL заполнен).

## ЧАСТЬ 5. Проверка терминала (30 секунд)

Терминал один — как у Claude Code, без переключения режимов. Проверь три вида ввода:

| Введи в терминал | Что должно произойти |
|---|---|
| `кто ты?` | стрим ответа AresCode-V1, в конце `Forged for …s` |
| `!echo привет` | прямая shell: шаг `⏺ Bash(echo привет) · exit 0` и вывод `привет` |
| `создай hello.py с выводом ARES и запусти` | `┌─ ПЛАН` → `⏺ Write(hello.py…)` → `⏺ Bash(python3 hello.py) · exit 0` → `✔ готово…`; файл придёт документом в чат бота |

В шапке сверху тикает HUD: CPU/RAM/DISK и `TOK …/1M | REQ …/1000` (обновление 5 с).
Кнопки внизу: 📦 АРХИВ (zip проекта), ❄ ХОЛОД (в почту), 🧹 УБОРКА (dry-run), ⚡ СТАТУС.
Кнопка `⚡AUTO` в шапке переключает сложность: AUTO → FAST → MAX.

## ЧАСТЬ 6. OmniRoute — резерв №4 (добавлен, осталось включить)

OmniRoute уже встроен в цепочку последней ступенью. Включение:

1. В cmd: `npm install -g omniroute`
2. Отдельное окно: `omniroute` → откроется дашборд http://localhost:20128
3. В дашборде: **Providers** → подключи хоть один бесплатный аккаунт
   (например OpenRouter или Groq — у них есть free-тарифы).
4. **Endpoints** → **Create API key** → скопируй ключ.
5. В .env: `OMNIROUTE_API_KEY=<скопированный ключ>` → перезапусти `python api.py`.
6. Проверка: у бота `/health` — `omniroute: OK …ms`.

Как это работает: запрос всегда идёт в GLM-4.7-Flash. Как только видимый тебе
лимит кончается (429/квота) — ARES сам, без твоего участия, перекидывает
поток дальше: **Gemini Flash → OpenRouter :free → OmniRoute** (а OmniRoute
внутри себя ещё и сам перебирает подключённые бесплатные пулы). В терминале
это видно строкой `» provider …`.

## ЧАСТЬ 8. Хостинг: ответы на твой вопрос

**GitHub Pages и Cloudflare Workers НЕ подходят** для ARES CODE:
- **GitHub Pages** умеет только отдавать статичные html/js — Python-процесс,
  бота и SQLite там запустить некуда. У нас же весь ARES — один живой процесс.
- **Cloudflare Workers** — «серверлес»: код живёт секунды на запрос, нет
  постоянного процесса, нет SQLite на диске, aiogram-polling невозможен.

**Что выбрать бесплатно (по порядку предпочтения):**

| Вариант | Что надо | Плюс | Минус |
|---|---|---|---|
| **Свой ПК + cloudflared** (Часть 4) | ничего, 10 минут | всё бесплатно, полные лимиты, нет ограничений хостинга | терминал жив, пока включён комп |
| **Render.com (free)** | аккаунт GitHub → New Web Service из репо, Build `pip install -r requirements.txt`, Start `python api.py` | постоянный HTTPS-адрес `*.onrender.com`, работает без твоего ПК | free-инстанс засыпает через 15 мин без трафика; лечится пингом: cron-job.org → GET `/healthz` каждые 10 мин |
| **VPS-бесплатки** (Oracle Cloud free tier и т.п.) | карта для верификации | 24/7 без сна | лишние сложности на старте |

Схема одна и та же: `BASE_URL` = HTTPS-адрес Render/tуннеля → перезапуск →
кнопка «◆ Open Ares Code» у /start.

### Render.com по кликам (подробный маршрут)

**А. Код в GitHub (~10 минут, один раз)**

1. Зарегистрируйся на https://github.com (если аккаунта нет).
2. Скачай **GitHub Desktop**: https://desktop.github.com → установи → войди под своим аккаунтом GitHub.
3. Меню **File → Add local repository…** → кнопка **Choose…** → выбери папку `ares_code` → появится ссылка
   **«create a repository here instead»** → кликни её.
4. Name: `ares-code` → кнопка **Create Repository**.
5. В списке изменений (слева) проверь глазами: файла **.env быть не должно** (его скрывает .gitignore — это нормально).
6. Внизу: поле Summary → напиши `ares code` → **Commit to main**.
7. Кнопка **Publish repository** → оставь включённым «Keep this code private» → **Publish**.

*Без установки (альтернатива):* github.com → New repository → выбери **Private** → Create →
ссылка «uploading an existing file» → перетащи туда все файлы и папки из `ares_code`
(кроме .env!) → Commit changes.

**Б. Render: создаём сервис (~5 минут)**

1. Открой https://render.com → **Get Started** → **Sign in with GitHub** → разреши доступ.
2. В Dashboard нажми **+ New** (справа сверху) → **Web Service**.
3. Найди в списке репозиторий `ares-code` → **Connect**. Если его нет — кликни
   «Configure account» на GitHub и дай Render доступ к репозиторию.
4. Заполни форму создания:
   - **Name**: `ares-code` (адрес сервиса станет `https://ares-code.onrender.com`)
   - **Language / Runtime**: **Python 3**
   - **Branch**: `main`
   - **Region**: **Frankfurt (EU Central)** — ближе всего к России
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `python api.py`  ← Render сам подставит свой порт, ничего менять не надо
   - **Instance Type**: **Free**
5. Раскрой **Advanced → Add Environment Variable** и добавь минимум (остальное добавим массово):
   `BOT_TOKEN` (твой токен), `OWNER_TELEGRAM_IDS` = `5188446459`,
   `GLM_API_KEY` (реальный ключ), `BASE_URL` = `https://ares-code.onrender.com`
   (имя сервиса подставь своё!).
6. Жми **Create Web Service** → пойдут логи сборки (2–4 минуты).
7. Жди в логах строк `ARES CODE запущен: TOK 0/1.00M…` и `бот запущен (polling)`,
   а вверху статус **Live**.
8. Открой в браузере `https://<имя>.onrender.com/healthz` → должно быть `{"ok": true…}`.

**В. Остальные секреты — массово за один раз**

1. В Render открой свой сервис → слева **Environment**.
2. Кнопка **+ Add from .env** → открой `env.local.txt`, скопируй ВЕСЬ текст в поле.
3. До вставки поправь в нём три вещи:
   - `BASE_URL=https://<имя>.onrender.com` (твой реальный адрес Render);
   - `GLM_API_KEY=<реальный ключ>` (не заглушка);
   - строки `OMNIROUTE_*` можешь удалить — на Render OmniRoute не живёт (это локальный
     роутер для домашнего ПК; в облаке цепочка GLM→Gemini→OpenRouter работает сама).
4. **Save & Deploy** (или «Save, rebuild and deploy») → сервис перезапустится с секретами.

Не добавляй на Render: `PORT` (Render ставит свой), `BOT_POLLING` (по умолчанию 1),
`ALLOW_UNAUTH_DEV` (на сервере всегда 0 — просто не добавляй).

**Г. Финал в Telegram**

1. Telegram → твой бот → **/start** → кнопка **◆ Open Ares Code** → терминал открылся.
2. **Обязательно** keep-alive (иначе Render уснёт через 15 мин и бот умолкнет):
   - https://cron-job.org → Sign up → **Create cronjob**
   - Title: `ares keepalive`, URL: `https://<имя>.onrender.com/healthz`
   - Расписание: **Every 10 minutes** → Save → включи тумблером.
3. Проверка терминала — как в Части 5.

**Д. Что важно знать на free-плане Render**

| Особенность | Что делать |
|---|---|
| Сон после 15 мин без HTTP-запросов; пробуждение ~1 мин | cron-job.org каждые 10 минут (см. Г-2). 750 ч/мес хватает на 24/7 |
| **Файловая система временная**: каждый деплой/рестарт стирает `data/` (доступы, реестр) и `workspace/` | Владелец входит всегда; остальных одобряй заново после рестарта; проекты держи в холоде (📦 → ❄) и возвращай `/restore` |
| Новый код: GitHub Desktop → Commit → Publish | Render пересобирает сам при каждом push (auto-deploy) |
| Смена переменных | Environment → правки → **Save & Deploy** |
| Сборка упала | Открой Logs → чаще всего помогает добавить переменную `PYTHON_VERSION` = `3.12.10` → Save & Deploy |

## ЧАСТЬ 9. Если что-то не завелось

| Симптом | Причина и лечение |
|---|---|
| `409 Conflict` в консоли | запущены два ARES одновременно (например, на ПК и на Render). Останови один |
| Кнопка Mini App не приходит | `BASE_URL` пуст или не `https://`. Проверь .env, перезапусти |
| Терминал открывается, но «ДОСТУП ОГРАНИЧЕН» | ты открыл не из Telegram-кнопки (нет подписи initData). Открывай через «◆ Open Ares Code» |
| GLM: 401/ключ недействителен | проверь GLM_API_KEY в .env, нет пробелов, перезапусти |
| GLM: 429 | лимит — это норма: failover сам уйдёт на резерв. Хочешь больше — новый ключ/окно |
| mail.ru: auth failed | в .env должен стоять именно **пароль внешнего приложения** (Почта → Настройки → Безопасность → Пароли внешних приложений), не пароль входа |
| `pip` не найден | venv не активирован: `.venv\Scripts\activate` |
| Python не найден | в установщике не поставил «Add to PATH» — переустанови с галочкой |

**Безопасность (важно):**
- `.env` никогда не выкладывай (он и в zip не попадает, и в архивы проектов — тоже).
- Токен бота и пароли ящиков были вставлены в чат — считается, что они «светились»:
  при желании перевыпусти их (BotFather → /revoke; mail.ru → перегенерируй пароли
  внешних приложений) и обнови .env. Это 5 минут.

## Глоссарий (расшифровка терминов)

| Термин | Что это |
|---|---|
| **Mini App** | мини-приложение внутри Telegram; кнопка под /start открывает наш терминал |
| **initData** | подписанный Telegram «паспорт» пользователя, которым Mini App доказывает серверу, кто он |
| **SSE (Server-Sent Events)** | поток ответа от сервера к браузеру — текст печатается по ходу генерации |
| **Failover** | автоматическое переключение на запасного провайдера при ошибке/лимите |
| **HUD** | строка-приборка сверху: CPU/RAM/DISK и расход токенов/запросов |
| **Токен** | «слог» текста, единица оплаты LLM; в бюджет пишется реальный usage провайдера |
| **WARN / ECONOMY / BLOCKED** | уровни бюджета дня: 80% — предупреждение, 90% — экономный режим, 100% — стоп |
| **Компакция** | сжатие истории диалога, чтобы не переплачивать за старый контекст |
| **Агент-цикл** | план → запись файлов → запуск → чтение ошибок → исправление → done |
| **Плагины** | софт с GitHub, который агент ставит в workspace/<проект>/plugins и удаляет по просьбе |
| **Песочница** | изолированный исполнитель команд: белый список программ, лимиты памяти/времени, без доступа к секретам |
| **Холодное хранение** | копия проекта письмом с вложением в твои почтовые ящики |
| **round-robin** | вращение по кругу: архивы уходят в ящики по очереди 1→2→3→4→1… |
| **sha256** | цифровой отпечаток файла; сверяется при восстановлении, чтобы ничего не побилось |
| **TTL** | время жизни; у корзины .trash — 24 часа, потом удаление |
| **passport.json** | опись внутри архива: список файлов, размеры, отпечатки |
| **tunnel (cloudflared)** | бесплатная труба, дающая вашему локальному порту публичный HTTPS-адрес |
| **keep-alive** | периодический пинг, чтобы бесплатный хостинг не заснул |
| **OmniRoute** | локальный роутер бесплатных LLM-пулов (один endpoint, сам перебирает провайдеров) |
